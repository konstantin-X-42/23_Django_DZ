Учебный веб-проект на базе фреймворка **Django**, реализующий базовую структуру сайта-каталога с интеграцией готовой фронтенд-верстки и формой обратной связи.

## 🛠 Выполненные задачи (Критерии проверки)

1. **Инициализация проекта:**
   * Развернуто Django-приложение внутри изолированного виртуального окружения.
   * Настроен файл зависимостей `requirements.txt`.
   * Настроен файл `.gitignore` для исключения системных файлов и базы данных `db.sqlite3` из репозитория.

2. **Маршрутизация и Архитектура:**
   * Создано изолированное приложение `catalog`.
   * Настроена независимая маршрутизация URL внутри приложения с использованием `include()` и строго с закрывающими слэшами (`/`).
   * Реализовано пространство имен (`namespace='catalog'`).

3. **Контроллеры и Шаблоны:**
   * В файле `views.py` созданы FBV-контроллеры для обработки страниц.
   * Интегрирована и адаптирована под стандарты Django готовая верстка страниц (Главная, Категории, Заказы, Контакты).
   * Статические файлы (CSS, Bootstrap-компоненты) успешно перенесены в директорию `static` и подключены в HTML через тег `{% static %}`.
   * Настроена сквозная навигация между всеми четырьмя страницами в боковом меню.

4. **Дополнительное задание (Форма обратной связи):**
   * На странице контактов реализована обработка отправки формы через метод `POST`.
   * Добавлен защитный токен `{% csrf_token %}`.
   * Данные формы (Имя, Почта, Сообщение) успешно принимаются контроллером и логируются в консоль сервера.
   * Добавлен динамический вывод сообщения об успешной отправке данных для пользователя на этой же странице.

## 🚀 Инструкция по запуску проекта

### 1. Клонирование репозитория
```bash
git clone <ссылка_на_твой_репозиторий>
cd 22_Django_DZ
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Применение миграций
```bash
python manage.py migrate
```

### 5. Запуск сервера разработки
```bash
python manage.py runserver
```
После запуска проект будет доступен в браузере по адресу: `http://127.0.0`

## 🌳 Структура проекта (основные файлы)
* `catalog/static/catalog/css/` — файлы стилей оформления.
* `catalog/templates/catalog/` — HTML-шаблоны страниц проекта.
* `catalog/views.py` — логика обработки запросов и рендеринга.
* `catalog/urls.py` — маршруты приложения.
* `config/settings.py` — основные настройки конфигурации Django.
